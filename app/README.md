# TenSei Upscale

A sleek, intuitive Android application for upscaling and enhancing image quality locally on your device.

## Features
- **High-Definition Upscaling**: Scale smoothly without aggressive pixelation.
- **Local Processing**: Keeps everything on your device for enhanced privacy.
- **Beautiful UI**: Modern, fluid interface with adaptive blur and glassy design.
- **Direct Gallery Save**: Saves to your Pictures folder in pristine quality.

## Setup
To build the project locally using Android Studio:
1. Clone this repository.
2. Open the project in Android Studio.
3. Sync Project with Gradle Files.
4. Run the `app` module on a device or emulator.
